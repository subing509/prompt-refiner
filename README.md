# 提示词打磨 · prompt-refiner

一个 Codex Skill：先把粗略需求整理成提示词，交给你编辑；等你明确说“开始执行”，再按最终版本工作。

## 工作流程

1. 提供原始需求，技能整理目标、背景、约束、交付形式和完成标准。
2. 在当前工作区生成独立的 Markdown 提示词文件，并尝试在 Codex 中打开。
3. 你修改并保存，也可以在聊天里提出修改意见。
4. 回复“开始执行”或“按这版做”，助手重新读取已保存的最新版，再执行任务。

仅回复“定稿”或“确认”不会自动执行。关键未知信息标为待补充，不擅自编造或扩大任务。

## 安装

将本仓库克隆到 Codex 的个人技能目录。若配置了 CODEX_HOME，请使用该目录下的 skills 文件夹。

```powershell
git clone https://github.com/subing509/prompt-refiner.git "$HOME/.codex/skills/prompt-refiner"
```

如果目标目录已有同名技能，请先检查现有内容，避免覆盖自定义修改。

## 使用

```text
用 $prompt-refiner 帮我完善这个需求：我想……
```

提示词保存在任务工作区，而不是技能安装目录。请保存编辑后再要求执行。

聊天中的代码块不能直接编辑。环境无法打开文件时，技能会提供文件链接，或请你复制到输入框修改后发回。

## 文件

- `SKILL.md`：技能指令。
- `agents/openai.yaml`：显示名称和默认调用提示。
